What it does

PresaleIQ connects your Odoo CRM to presaleiq.ai — an AI pre-sales platform that analyses discovery call transcripts and opportunity descriptions, then instantly generates:

  • 📄 Statement of Work (SOW) — ready to send to the prospect
  • 📋 User Stories & Acceptance Criteria — ready for your delivery team
  • ⏱ Effort Estimates — days / sprints / cost breakdown
  • 🔍 Low-Level Requirements (LLD) — technical specification
  • 📊 License Sizing — right-size the platform for the customer

How it works — 3 steps

1️⃣

Open an Opportunity

Any CRM opportunity with a description or attached transcript.

2️⃣

Click "Analyze with PresaleIQ"

One button sends the opportunity to PresaleIQ for AI analysis.

3️⃣

Get results in seconds

SOW, user stories, and effort estimates posted directly to the chatter.

Configuration

  1. Install the module.
  2. Go to Settings → PresaleIQ.
  3. Enter your PresaleIQ Instance URL (default: https://presaleiq.ai).
  4. Enter your API Key — generate one at presaleiq.ai/settings/api-keys.
